GitHub Copilot 4's

✅ Single, Specific, Short, and Surround.

💡 Explicación detallada:

La técnica 4S Prompt Crafting Technique se enfoca en cómo escribir prompts efectivos y eficientes para maximizar los resultados con GitHub Copilot (y cualquier asistente de código impulsado por IA).

Los 4S significan:

  1. Single → Un solo propósito.

    Cada prompt debe centrarse en una tarea concreta, por ejemplo: “Genera una prueba unitaria para el método savePolicy()” y no mezclar cosas como “genera la prueba y refactoriza la clase”.

  2. Specific → Sé específico.

    Indica exactamente lo que necesitas: lenguaje, framework, patrón, nivel de detalle. Ejemplo: “Crea un REST controller en Java 17 con Spring Boot 3.4 para registrar clientes.”

  3. Short → Breve y claro.

    Prompts cortos ayudan a que Copilot procese rápido y evite ambigüedades. Usa frases directas en lugar de párrafos largos.

  4. Surround → Da contexto suficiente.

    Menciona el archivo, clase o método relevante, o usa el # para incluir contexto. Ejemplo: “#PolicyService refactoriza el método calculatePremium() usando Optional.”

🧠 En resumen:

El 4S Prompt Crafting Technique ayuda a mantener los prompts rápidos, enfocados y contextuales, logrando que Copilot entienda exactamente qué hacer sin perder precisión.
